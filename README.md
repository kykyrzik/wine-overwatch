# Overwatch 2 на Mac через Sikarugir — исправления Wine

Набор правок для движка Wine в обёртке Sikarugir, с которыми Overwatch 2 запускается и нормально играется на Apple Silicon.
Репозиторий не содержит ни Wine, ни игры, ни Battle.net — только описание правок и скрипт, который вносит их в вашу копию движка.

Проверено: Apple M5, macOS 26.6, движок `WS11WineSikarugir11.0_1`, рендер DXMT.

## Что исправляется
- **Игра зависает при загрузке** — бесконечный цикл в обработчике сигналов Wine (`ntdll.so`).
- **Мышь в бою** — камера дёргалась, «уплывала», курсор упирался в край.
- **Рывок камеры при выстреле** (ЛКМ/ПКМ) и при прокрутке колеса.
- **Полноэкранный режим** — мышь в бою работает, в меню курсор свободный.
- **Микрофон в голосовом чате** — macOS не выдавала обёртке доступ (отдельный инструмент, см. ниже).

Подробно, что и где меняется, — в [docs/patches.md](docs/patches.md).

## Установка
1. Установите Sikarugir, создайте обёртку на движке **WS11WineSikarugir11.0_1**, установите в неё Battle.net и Overwatch и войдите в свою учётную запись.
2. Полностью закройте игру, Battle.net и обёртку.
3. Примените правки:
   ```bash
   ./ow-patch.sh status ~/Applications/Sikarugir/<ваша обёртка>.app
   ./ow-patch.sh apply  ~/Applications/Sikarugir/<ваша обёртка>.app
   ```
   Скрипт проверяет версию движка по SHA-256 и каждую правку по исходным байтам. Если сборка другая — ничего не меняет.
4. Микрофон (нужны Xcode Command Line Tools: `xcode-select --install`):
   ```bash
   ./tools/mic-access/grant-mic.sh ~/Applications/Sikarugir/<ваша обёртка>.app
   ```
   Появится системный запрос доступа к микрофону от имени обёртки — нажмите «Разрешить».

## Рекомендуемые настройки
- **Разрешение**: в полноэкранном режиме ставьте разрешение экрана в точках (для MacBook Pro 14" — 1512×982) и «Масштаб рендеринга» 200%.
  Максимальное разрешение в пикселях Retina (3024×1964) сдвигает курсор в меню: Wine работает в точках, а игра считает их пикселями.
- **Battle.net → Настройки → При запуске игры → «Закрыть Battle.net полностью»**. Иначе Battle.net иногда забирает фокус,
  и в полноэкранном режиме мышь в меню перестаёт действовать, хотя игра остаётся на экране.
- Первые игры на новых картах и героях будут с микрофризами — это компиляция шейдеров DXMT, она кэшируется. Кэш не удаляйте.

## Откат
```bash
./ow-patch.sh revert ~/Applications/Sikarugir/<ваша обёртка>.app
```
Скрипт хранит оригиналы рядом с файлами (`*.ow-orig`) и восстанавливает их.

## После обновления Sikarugir
Правки привязаны к конкретной сборке движка. Новую сборку скрипт не тронет; как перенести правки — [docs/porting.md](docs/porting.md).
Разрешение на микрофон тоже может слететь — повторите `grant-mic.sh`.

## Важно
- Blizzard официально не поддерживает запуск через Wine. Правки меняют только драйвер ввода и загрузчик Wine, саму игру не трогают, но играете вы на свой риск.
- Не выкладывайте свою обёртку целиком: в её префиксе лежат файлы игры и данные вашей учётной записи Battle.net.
